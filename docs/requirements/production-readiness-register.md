# Production Readiness Register

**Date**: 2026-10-21

**Status**: **OPEN.** Every entry below is outstanding. This register records the compliance,
provider, and security decisions that must be resolved before a production acceptance, and it names
the owner of each one. It complements
[the open decisions register](../requirements/open-decisions.md), which records the **business**
decisions; this one records what remains between a complete development baseline and a production
acceptance.

## The register's state

**No entry above is closed.** The platform's development baseline is complete and verified; the
production acceptance depends on every row of this register and on every item of the
[deferred acceptance checklist](../operations/deferred-acceptance-checklist.md).

The register is deliberately written as **decisions**, not as tasks, because each row names a choice
that only the merchant or the operations owner can make. The engineering work that does not depend
on those choices has been done and evidenced.
